# ML4WX repo

Archive of ML research for weather and climate: data (`papers/`), pipeline (`src/ml4wx/`),
static site (`src/ml4wx/site/`), GitHub Actions (`.github/workflows/`).

- Python with `uv`: `uv sync --extra site`, `uv run pytest -q`, `uv run ruff check src tests`.
- CLI: `uv run ml4wx --help`. Main commands: `validate`, `weekly`, `alerts --dry-run`,
  `backfill`, `snowball`, `seed`, `export`, `site --out _site`.
- Preview the site: `uv run ml4wx site --out _site && python -m http.server -d _site 8000`.
- Config is data: topics and facets in `config/taxonomy.yaml`, search queries and prefilter
  patterns in `config/sources.yaml`, labs in `config/watchlist.yaml`, scores in `config/settings.yaml`.
  Topic slugs are stable ids: never rename one.
- One YAML per paper: `papers/<year>/<id>.yaml`, schema in `src/ml4wx/models.py` (`Paper`).
- Resources (datasets, models with public code/weights, software): one YAML per entry in
  `resources/{datasets,models,software}/<slug>.yaml`, vocabulary in `config/resources.yaml`,
  code in `src/ml4wx/resources.py`. `resources/_github.json` is generated weekly
  (`ml4wx resources refresh`): never edit it by hand. Add a batch with `ml4wx resources import FILE`
  (a YAML list); verify every URL and repo before adding.
  `README.md`, `lists/` and `exports/` are generated by `ml4wx export`: edit the templates in
  `src/ml4wx/site/templates/`, not the outputs.
- Site extras: `src/ml4wx/insights.py` (topic stats, trends, related papers with TF-IDF via
  scikit-learn) and `src/ml4wx/site/charts.py` (server-side SVG charts using the theme's CSS
  variables, one hue per chart, table view per chart).
- LLM calls go through the Claude Code CLI (`claude -p`, see `src/ml4wx/llm.py`) because the
  project runs on a Claude subscription token (`CLAUDE_CODE_OAUTH_TOKEN`), not an API key. Keep
  calls batched; every call counts against the subscription limits.
- OpenAlex has a daily budget per key ($1/day with the free key; $0.10/day shared without a key).
  Heavy OpenAlex work runs in GitHub Actions where `OPENALEX_API_KEY` is set.
- Never print or commit secrets (`CLAUDE_CODE_OAUTH_TOKEN`, `OPENALEX_API_KEY`, `S2_API_KEY`).
