About ML4WX

ML4WX is an open archive of machine learning and AI research for weather and climate. It started with a deep search of the literature since {{ cfg.settings.start_year }} (plus a curated set of older classics) and grows every week.

How it works

  1. Weekly, Monday morning (Zurich time). A GitHub Action searches arXiv (physics.ao-ph and the ML categories) and OpenAlex (journals and conferences) for new papers. Claude reads each title and abstract and decides relevance, topic, method, time scale, data and a one-sentence summary. Organizations come from OpenAlex affiliations and the arXiv HTML title page. The result is a pull request that a maintainer reviews.
  2. Daily. The same pipeline looks for important new papers and lab blog posts and opens a GitHub issue with the highlight label, so watchers hear about them the same day.
  3. On every merge. This site is rebuilt and the search index is regenerated.

How highlights work

Each paper gets an importance score from 0 to 100. Points come from a tier-1 lab ({{ cfg.settings.highlight.weights.org_tier1 }}), a tier-2 lab ({{ cfg.settings.highlight.weights.org_tier2 }}), a top venue ({{ cfg.settings.highlight.weights.top_venue }}), open code ({{ cfg.settings.highlight.weights.open_code }}), operational use ({{ cfg.settings.highlight.weights.operational }}), many citations (older papers), and {{ cfg.settings.highlight.weights.significance }} × a 0–10 significance judgment by Claude. A paper is a highlight when its score is {{ cfg.settings.highlight.threshold }} or more and its significance is at least {{ cfg.settings.highlight.min_significance }}, or when its significance is {{ cfg.settings.highlight.always_significance }} or more. So a big lab alone is not enough, and landmark work from anywhere is included.

How essentials are chosen

The Essentials are the papers, models, datasets and tools to know first. Candidate papers are highlights, classics and papers with a significance of {{ ess.landmark }} or more; all need a significance of at least {{ ess.min_significance }}. They are ordered by citations per year since publication. The age counts as at least one year, so a paper from last month does not jump ahead with a few early citations. The essentials are papers from {{ ess.since }} on, and the first {{ ess.size }} of them are the essentials for all topics; older candidates are listed apart as "Before {{ ess.since }}". Maintainers can add or remove a paper by hand. Models, datasets and tools keep the order of their own pages: a curated rank for the most used ones, then GitHub stars and the citations of their paper.

Data and reuse

  • One YAML file per paper in papers/.
  • BibTeX, CSV, JSON, RSS (all), RSS (highlights).
  • Abstracts are shown only when their license allows it (arXiv metadata, CC BY, CC0). Labels and summaries are generated by Claude and may contain errors.

Contribute

Missing paper or wrong label? Open an issue with the arXiv id or DOI, or use the "Edit this entry" link on any paper page.
